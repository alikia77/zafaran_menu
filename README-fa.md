# منوی زعفران — بسته‌ی کامل پروژه

این پوشه همه‌چیز پروژه را دارد: کد، عکس‌ها، کتابخانه‌ها، اسکریپت‌های ساخت عکس و یک «حافظه» برای Claude.

## ادامه دادن در Claude Code یا یک گفتگوی جدید
1. کل این پوشه را باز کن (یا در یک ریپوی گیت‌هاب بگذار).
2. به Claude بگو: «فایل CLAUDE.md را بخوان و از همان‌جا ادامه بده».
   در CLAUDE.md هدف پروژه، سلیقه و قوانین طراحی، ساختار کد، کارهای انجام‌شده و قدم‌های بعدی کامل نوشته شده.

## ساختن و دیدن سایت
```
python3 build.py
cd dist && python3 -m http.server 8765
```
بعد در مرورگر: http://localhost:8765

## انتشار روی گیت‌هاب
محتوای پوشه‌ی `dist` را در ریشه‌ی ریپوی `alikia77/zafaran_menu` بگذار و push کن.
لینک: https://alikia77.github.io/zafaran_menu/

## پوشه‌ها
- `src` — کد سایت (HTML، CSS، جاوااسکریپت)
- `p` — همه‌ی عکس‌های نهایی (غذاها، هدرها، مواد، لیوان‌ها)
- `lib` — کتابخانه‌های انیمیشن و QR
- `pipeline` — اسکریپت‌های برش عکس، ساخت هدر و لیوان خالی + لیوان‌های خالی اصلی
- `tools` — اسکریپت عکس‌گرفتن از صفحه برای تست
- `CLAUDE.md` — حافظه‌ی کامل پروژه برای Claude
